# 智能体统计数据架构

## 目标

智能体统计独立于账单、视觉诊断与聊天界面，通过 `AgentAnalyticsViewModel` 统一读取。界面禁止直接扫描聊天记录、诊断截图、无障碍节点或操作学习正文。

当前架构同时满足三条边界：

- 本地数据按访客或 Supabase 账号严格隔离。
- 登录账号只同步按天聚合的数值统计。
- 任务目标、执行结果、应用名称、动作文本和逐次 Token 事件默认只留在本机。

## 数据来源

### 普通聊天

`AssistantMemoryUsageBridge` 在一次逻辑聊天请求完成后旁路记录：

- 模型与供应商标识
- 成功或失败
- 真实请求、响应字节数
- 网络耗时
- 输入、输出、推理、缓存与总 Token
- 联网搜索
- 图片理解请求
- 结构化工具与内部能力调用

请求字节复用传输层已经生成的 UTF-8 数据，流式响应字节原位累计，避免为了统计再次序列化包含图片的整份请求。备用端点只属于同一逻辑聊天请求的传输容错，不会虚增会话数量。

### GUI Plus / 视觉智能体

`VisualAgentClient` 与 `AgentRuntimeController.progress` 旁路记录：

- 任务开始、结束、结果与持续时间
- 模型规划轮次与模型失败
- 执行动作、动作成功与失败
- 重新观察、计划拒绝和执行失败
- 风险确认、用户输入、用户接管与恢复
- 自主完成与介入后完成
- 使用的动作与已验证目标应用
- 每次 GUI Plus 请求的 Token、字节数与耗时

任务创建时会固定 `ownerStorageKey`。即使执行期间切换账号，模型调用和终态仍写回任务开始时所属的数据空间，不会落入新账号。

统计逻辑不参与模型路由、页面理解、点击决策、完成许可、截图或无障碍模式切换。应用统计只接受经过打开应用路径确认过的应用名称。

### 操作学习 Skill

`AgentSkillInventoryRepository` 只在用户进入“能力”页签后执行一次只读聚合查询，不注册常驻数据库观察器，也不读取录制轨迹或 Skill 正文。

操作学习数据库目前仍是设备级资产。为避免账号切换时泄露设备上其他用户的 Skill 数量，登录账号统计页暂不合并这部分数据；访客空间仍可查看本机 Skill 聚合。

## Token 口径

每条 Token 数据带有准确性来源：

- `Provider`：云端响应返回真实 usage。
- `Estimated`：云端没有返回 usage 时，本地根据请求与响应文本保守估算。

缓存 Token 作为输入 Token 的子集单独保存，不重复计入总量。推理 Token 在多数协议中已经属于输出 Token，也不重复累计。Base64 图片不会按文本字符计数。

界面必须明确区分真实 Token 与估算 Token，不能把估算值展示成精确计费数据。

## 本地账号隔离

`AgentAnalyticsOwnerRuntime` 维护当前统计所有者：

- 未登录：`guest:<installationId>`，继续使用历史文件 `agent_analytics.db`。
- 已登录：`user:<Supabase userId>`，使用 `agent_analytics_user_<userId SHA-256 摘要>.db`。

账号切换只切换数据库，不自动搬运或合并访客历史。退出登录后账号数据库仍保留在 App 沙箱中，但不会在访客页面显示；再次登录同一账号后恢复。

数据库版本保持为 2，表结构没有因为账号隔离而增加重复的 `ownerId` 列，避免每次查询额外拼接过滤条件。隔离由独立 Room 文件完成。

### `agent_daily_activity`

按本地自然日聚合，是 Token 活动热力图和跨设备同步的唯一数据源。包含每日 Token、模型调用、任务结果、动作、观察、确认、输入、接管、联网与图片活动。

### `agent_token_events`

保留每一次模型请求的细粒度 Token 事件，只保存在本机。

### `agent_task_analytics`

保留任务目标与任务级摘要，只保存在本机。进程异常结束后，下次打开相应数据空间时会把未收口任务标记为中断。

### `agent_model_usage` 与 `agent_capability_usage`

分别保存模型和能力的本机累计数据，不上传详细模型排行、应用名称或动作名称。

## 云端账号聚合

Android 仅在以下条件同时满足时同步：

- 用户已登录且本地 session 可用。
- 智能体统计详情页处于可见状态。
- 本地账号数据库已经完成首次读取。

同步入口只访问主阿里云后端，不携带账号 JWT 访问备用公共端点。五分钟内重复进入页面且本地数据没有变化时，直接复用内存缓存。

云端表 `agent_analytics_daily_v1` 以 `(user_id, device_id, date_key)` 为主键。后端只信任已验证 JWT 中的 Supabase userId，忽略客户端自报账号，并通过 RLS 强制 `auth.uid() = user_id`。

每次上传的是当前设备发生变化的每日完整聚合行。读取时 RPC 排除当前设备并汇总其他设备，Android 再把其他设备聚合与当前本机数据相加，从而避免当前设备被重复统计。

云端默认不接收：

- 任务目标与执行结果
- 应用名称与动作文本
- 单次请求事件
- 聊天正文、截图或无障碍节点
- Skill 正文与录制轨迹

云端不可用、尚未部署表结构、登录过期或请求超时时，统计页自动退回本机数据，不影响聊天、智能体、记忆、账单或操作学习功能。

## 保留策略

- 本地每日聚合：5 年
- 本地 Token 细粒度事件：2 年
- 本地任务摘要：最近 1000 条
- 页面默认加载最近 100 条任务

云端聚合由账号表长期保存，用户删除账号时通过外键级联删除。后续增加“删除云端统计”入口时，可直接使用现有 RLS 删除策略，不需要开放服务端管理员密钥。

## 页面指标

- 累计 Token、峰值日 Token与每日活动热力图
- Provider Token 与 Estimated Token 占比
- 当前与最长连续活跃天数
- 聊天请求、模型调用与失败率
- 任务总数、完成数、成功率与自主完成率
- 模型规划轮次、动作、重新观察和计划拒绝
- 总任务时长与本机最长任务时长
- 本机最常用模型、能力、动作和应用
- 确认、输入、接管、联网与图片理解活动

跨设备只合并每日数值聚合；最长单任务、最近任务、模型排行和能力名称仍明确使用本机数据。

## 安全和性能约束

- 所有数据库写入与云同步都在 IO 协程中完成。
- Room 聚合 Flow 使用 `WhileSubscribed`；页面关闭后取消数据库观察与云同步协程。
- 高频视觉循环只更新内存，任务终态一次性落库。
- 云同步请求不经过聊天统计传输层，不会把同步本身计入模型调用或 Token。
- 统计异常全部旁路降级，不能反向影响聊天、智能体或账号登录。
- 不增加无障碍事件监听，不主动扫描节点，不额外截图。
- 不修改 OpenGL 聊天框稳定系统、聊天气泡父级绘制链或任何玻璃 registry。
